# Scacchi & Chill: notes for coding agents

## Language

Everything about the code is written in English:

- identifiers, comments and documentation comments in the source
- test names and descriptions
- commit messages, branch names, pull request titles and descriptions
- notes in configuration files about how the code works (for example the `_readme` of `config.json`)

What the people of the tournament read stays in Italian: the texts of the site and of the organizer
area, the WhatsApp messages and phrases (`config.json`), the notifications, and the `README.md`,
which is written for the organizer.

`AGENTS.md` is a link to this file: edit `CLAUDE.md` only.
